  Jev 模型游乐场 · 怎么启动
═══════════════════════════════════════════════

【推荐】不用装 Python —— 下载独立程序版
───────────────────────────────────────────────

  在 GitHub 的 Releases 页面下载对应系统的 zip：

    Windows  → 解压后双击  Jev游乐场.exe
    Mac      → 解压后双击  Jev游乐场.app

  浏览器会自动打开 http://127.0.0.1:8800/

  Mac 首次若提示「无法打开」：
    右键 Jev游乐场.app → 打开 → 再点「打开」

  关闭：关掉弹出的黑色窗口（或 Mac 上 Cmd+Q 退出程序）


【备选】源码 zip —— 需要电脑上有 Python
───────────────────────────────────────────────

  ① 解压 zip
  ② Mac 双击 start-mac.command
     Windows 双击 start-windows.bat
  ③ 浏览器自动打开

  没有 Python？去 python.org/downloads 安装 3.10+
  Windows 安装时勾选 Add python.exe to PATH


没 API Key 也能玩
───────────────────────────────────────────────

  吃豆人 → 选手工模式 → 开始游戏

  想用 AI：用记事本打开 .env
  在 TYPESAFE_API_KEY= 后面填 key，保存后重新启动
