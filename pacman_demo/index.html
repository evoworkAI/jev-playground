接口配置

base url / model 会预填成服务端 .env 的默认值，随时可以改；改完只存在浏览器 localStorage 里。
API key 不放在页面里 —— 它留在服务端 .env（ TYPESAFE_API_KEY / LLM_API_KEY），页面只拿到掩码； 只有你在这里手动填了 key，它才会存进 localStorage。
请求统一经由本地服务 /api/* 转发 —— Jev 的 API 不允许浏览器跨域直连（预检会被拒），这是预期行为。
